Revoke Device

Remove an employee's registered device so a new one can be registered.

Add Employee

The Employee ID is assigned automatically (the next EMP number), the joining date is today, and the status is set to Active.

Remove Employee

This changes the employee's status from Active to Inactive. If they still have a registered device, revoke it from the Revoke Device tab.
